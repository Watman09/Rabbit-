# Rabbit Reaper — боевой прототип

Браузерная боевая песочница на **Godot 4.3 (GDScript)**: заяц-жнец с огромной косой
против бесконечных волн тёмных духов. Цель прототипа — боевая система, которую
приятно ощущать и легко расширять дальше (мир, сюжет, прокачка — позже).

## Запуск

* **Играть в браузере / на телефоне (GitHub Pages):** готовая сборка лежит в `docs/`.
  Settings → Pages → Source: *Deploy from a branch* → ветка с проектом, папка `/docs`.
  Игра откроется по адресу `https://<user>.github.io/<repo>/`.
  Для приватного репозитория Pages требует платный план GitHub — иначе репозиторий нужно сделать публичным.
  Обновить сборку: `godot --headless --export-release "Web" docs/index.html`.

* **Редактор:** открыть папку в Godot 4.3+ → F5.
* **Веб-сборка:**
  ```bash
  godot --headless --export-release "Web" docs/index.html
  cd docs && python3 -m http.server 8000   # открыть http://localhost:8000
  ```
  Сборка однопоточная (`thread_support=false`), поэтому **не требует COOP/COEP-заголовков**
  и работает на любом статическом хостинге (itch.io, GitHub Pages).
  Рендерер — `gl_compatibility` (WebGL 2).
* Параметры URL для тестов: `?autostart` — сразу в бой, `?stress=120` — заспавнить 120 духов.

## Управление

| Клавиатура / мышь | Действие |
|---|---|
| WASD / стрелки | движение |
| ЛКМ (J) | комбо косой из 4 ударов: Жатва → Возврат → Восходящий серп → Мрачный вихрь (360°) |
| ПКМ удерж. (K) | заряженная «Казнь»: вертикальный удар + ударная волна; при полном заряде — летящий серп |
| Пробел / Shift | рывок с неуязвимостью (2 заряда); атака сразу после рывка — рывковый удар |
| Q | **Вихрь душ** — вращение, затягивающее духов, финальный взрыв |
| E | **Багровый серп** — пробивающий снаряд-полумесяц |
| R | **Жатва душ** (нужна полная шкала душ) — прыжок и удар по области, добивание, лечение |
| Esc / P | пауза |
| F3 / F9 | отладка: FPS/draw calls · +60 духов (стресс-тест) |

Геймпад поддерживается (левый стик, X/Y/A/LB/RB/B). На сенсорных экранах автоматически
появляются плавающий джойстик и кнопки; прицел — автонаведение на ближайшего духа.

Атаки направлены в сторону курсора; удары косы срезают вражеские снаряды.

## Враги

| Дух | Поведение |
|---|---|
| **Огонёк** (wisp) | быстрый, кружит стаями и делает телеграфированный бросок |
| **Призрак** (wraith) | ближний бой: поднимает когти (телеграф), рвёт конусом |
| **Плакальщица** (banshee) | держит дистанцию, стреляет веером сгустков |
| **Тень** (shade) | крупный призрак, при смерти распадается на 3 огонька |
| **Колосс мрака** (brute) | танк, устойчив к отбрасыванию; удар по земле и таран по линии |
| **Элитные** | любой тип ×4 HP, крупнее, ярче, больше душ (с 3-й волны) |
| **Скорбящая Пустота** (босс) | каждая 10-я волна; 3 фазы: удары когтями, кольца снарядов, призыв, таран, извержения |

После босса цикл повторяется с ростом сложности (бесконечный режим).
Реакции на попадание: вспышка, «сплющивание», отбрасывание/подброс, сбитый замах,
искры; смерть — растворение по шуму с горящей кромкой, дым, угли и «осколки» духа,
разлетающиеся и рассеивающиеся (этапы рассеивания из концепта). Души вылетают
и затягиваются в жнеца, наполняя шкалу ультимейта и понемногу леча.

## Архитектура

```
scripts/
  autoload/   events.gd (шина сигналов) · game.gd (состояние, hit-stop, коллизии арены, input map)
              fx.gd (следы, частицы, телеграфы, ударные волны, послеобразы) · sfx.gd (синтез звука)
  core/       damage_info.gd (единое описание удара) · attack_data.gd (Resource атаки)
  player/     player.gd (FSM: MOVE/ATTACK/DASH/CHARGE/CAST/DEAD) · player_input.gd (устройства → намерения)
              player_rig.gd (процедурная анимация тела и косы) · moveset.gd (данные атак)
              abilities/ ability.gd (база) + soul_maelstrom / crimson_crescent / harvest_of_souls
  enemies/    enemy.gd (база) + wisp / wraith / banshee / shade / brute / boss
              enemy_manager.gd (центральный апдейт, spatial hash, разделение, тени)
              spirit_mesh.gd (процедурные меши духов) · spirit_renderer.gd (MultiMesh на тип)
              enemy_projectiles.gd (пул снарядов)
  waves/      wave_director.gd (бюджет волн, разблокировка типов, элиты, босс)
  fx/         soul_manager.gd · crescent_wave.gd
  world/      arena.gd (процедурная арена) · game_camera.gd (камера, тряска, look-ahead)
  ui/         hud.gd (immediate-mode HUD) · touch_controls.gd
tools/        build_hero_meshes.gd (разделение FBX на тело и косу) · test_runner.gd (автотест/скриншоты)
```

**Как расширять**

* *Новая атака* — новый `AttackData` в `moveset.gd` (тайминги, дуга, радиус, цвета следа);
  код не нужен. Комбо = массив `AttackData`.
* *Новая способность* — наследник `Ability` (`_begin`, `_update` → `true` по завершении),
  добавить в `Player.abilities`.
* *Новый дух* — наследник `Enemy` с `_think()`, пресет внешности в `SpiritMesh.PRESETS`,
  регистрация в `EnemyManager.TYPES` и `WaveDirector.COST/UNLOCK`.
* Весь урон идёт через `DamageInfo` и `Player.deal_damage()` / `Enemy.take_hit()` —
  сюда же лягут статусы, вампиризм, крит и т.п.
* Скелетная модель позже заменит только `PlayerRig` (сейчас тело и коса позируются кодом,
  т.к. исходный FBX — статичный меш без скелета).

**Производительность (браузер)**

* Без физического движка: кинематика на плоскости XZ + круговые коллизии.
* Все духи одного типа рисуются **одним MultiMesh** (данные в `INSTANCE_CUSTOM`),
  тени — одним MultiMesh, души и снаряды — тоже MultiMesh. Сотня духов ≈ десятки draw calls.
* Центральный апдейт врагов + пространственный хеш (разделение и запросы попаданий за O(n)).
* Пулы частиц, кэш мешей следов, адаптивное снижение количества частиц при падении FPS.
* Звук синтезируется при старте (ассетов нет), по 2 звука за кадр — без фриза.

## Ассеты

* `assets/models/rabbit_reaper.fbx` — исходная модель. `hero_body.res` / `hero_scythe.res`
  генерируются `tools/build_hero_meshes.gd` (разделение по связным компонентам + палитра
  в vertex colors): `godot --headless -s res://tools/build_hero_meshes.gd`.
* Шейдеры — `assets/shaders/` (дух, след косы, свечение, пол, камень, наземные эффекты).

## Автотест

xvfb-run godot --rendering-driver opengl3 --fixed-fps 60 -s res://tools/test_runner.gd -- /tmp/shots combat
