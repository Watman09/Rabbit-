# Audio

Drop real sound files here (`.ogg` preferred, `.mp3`/`.wav` also work). A file
named after a sound replaces its synthesised placeholder automatically:

| file | when it plays |
|---|---|
| `music.ogg` | background music (looped) |
| `swing.ogg`, `swing_big.ogg`, `heavy.ogg` | scythe swings |
| `hit.ogg`, `kill.ogg` | hitting / banishing a spirit |
| `soul.ogg` | soul pickup (pitched up on streaks) |
| `dash.ogg`, `step.ogg` | dash, footsteps |
| `hurt.ogg`, `player_death.ogg` | the Reaper is hit / falls |
| `claw.ogg`, `telegraph.ogg`, `bolt.ogg`, `slam.ogg`, `portal.ogg` | spirit attacks and spawns |
| `roar_small.ogg`, `boss_roar.ogg` | colossus / boss |
| `charge.ogg`, `charged.ogg` | heavy charge start / full |
| `ability_whirl.ogg`, `ability_crescent.ogg`, `ability_harvest.ogg` | abilities |
| `perfect.ogg`, `parry.ogg`, `execute.ogg` | combat reactions |
| `wave.ogg`, `upgrade.ogg`, `denied.ogg` | wave start, upgrade screen, ability not ready |
| `click.ogg` | menu buttons |

Use only sounds you have the rights to (your own, licensed, or CC0).
