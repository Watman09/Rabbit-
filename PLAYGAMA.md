# Публикация Rabbit Reaper на Playgama

Пошаговая инструкция, чтобы выложить игру самостоятельно. Номера в скобках —
пункты официальных требований Playgama (wiki.playgama.com → Game Requirements),
по ним же проверяет модерация.

## Что уже сделано в проекте

| Требование | Как сделано |
|---|---|
| Bridge SDK v2.4.0 (1.1) | плагин `addons/playgama_bridge` + шаблон `html/shell.html`: SDK загружается и инициализируется **до** движка; рядом с `index.html` кладутся `playgama-bridge.js` и `playgama-bridge-config.json` |
| Язык из Bridge, английский по умолчанию (3.4.1–3.4.2) | `platform.language` при старте, EN — запасной язык; есть RU |
| Выбор языка понятен без знания языка (3.4.4) | иконка глобуса в главном меню, названия языков «English» / «Русский» |
| Сохранения только через Bridge Storage (3.2) | один ключ `rabbit_reaper_save`: рекорды (волна, комбо, убийства) + настройки + флаг обучения; запись только при смерти и смене настроек. IndexedDB движка отключён (`persistentPaths = []`) |
| Пауза/звук от платформы (3.3.4–3.3.5, 2.1.6) | `isAudioEnabled` на старте, события `audio_state_changed` / `pause_state_changed`; во время рекламы и при скрытой вкладке игра на паузе и без звука |
| `game_ready` (шаг 6 SDK) | отправляется, когда главное меню отрисовано и принимает ввод |
| Межстраничная реклама (2.1.2–2.1.3) | `showInterstitial()` при выходе с экрана смерти («Восстать снова» / «В меню»); частоту решает Bridge, своих таймеров нет |
| Кнопка выключения звука (3.3.3) | в главном меню и в игре (правый верхний угол) + в настройках |
| Нет Esc (1.5.2) | пауза — клавиша P, кнопка паузы на экране, Start на геймпаде |
| Мобильные устройства (1.4) | сенсорный джойстик и кнопки; долгое нажатие не выделяет текст и не открывает меню (CSS + `contextmenu`) |
| Обучение вместо стены текста (3.1.3) | подсказки при первом запуске: движение → удар → рывок → заряд → способности; повторить можно в настройках |
| Нарастающая сложность, рекорд (3.1.2, 3.2.2) | бесконечные волны, босс каждые 10 волн, рекорды сохраняются |
| Никаких внешних ссылок, аналитики, логинов (1.2) | нет |
| Название в игре (3.5.1) | **Rabbit Reaper** — так же назовите игру в заявке |

## Что нужно сделать вам до отправки

1. **Звук — обязательно (3.3.1–3.3.2).** Playgama **не принимает звук,
   синтезированный кодом**, а сейчас в игре именно такие звуки-заглушки. Нужны
   настоящие файлы `.ogg` (или `.mp3`) и фоновая музыка. Положите их в
   `assets/audio/` с именами из `assets/audio/README.md` (`music.ogg`,
   `swing.ogg`, `hit.ogg` …) — игра подхватит их сама, код менять не нужно.
   Берите только звуки, на которые у вас есть права (свои, купленные или CC0).
   Затем пересоберите (шаг «Сборка» ниже).
2. **Проверьте права на модель зайца (4.2.1) и пункт про генеративный ИИ (4.3.1):**
   модель должна быть вашей или лицензированной. Если она сгенерирована ИИ,
   модерация может придраться — будьте готовы показать, что визуал доработан.
3. **Пройдите игру сами** на компьютере и телефоне в Chrome, Firefox, Safari (1.7.3):
   меню, настройки, бой до смерти, «Восстать снова», смена языка, выключение звука.

## Сборка архива

В редакторе Godot 4.3: **Проект → Экспорт → Web → Экспортировать проект** в папку
`docs/` (пресет уже настроен: шаблон Bridge, без потоков). Или из консоли:

```bash
godot --headless --export-release "Web" docs/index.html
```

Затем заархивируйте **содержимое** папки `docs/` (не саму папку) в zip.
В корне архива должны лежать `index.html`, `index.js`, `index.wasm`, `index.pck`,
`playgama-bridge.js`, `playgama-bridge-config.json` (1.3.2). Файлы `.gdignore` и
`.nojekyll` можно не включать. Размер ~9 МБ в zip — лимит 300 МБ (1.3.1).

Linux/macOS:
```bash
cd docs && zip -r ../rabbit_reaper_playgama.zip . -x ".gdignore" ".nojekyll"
```
Windows: выделите файлы внутри `docs/` → ПКМ → «Отправить → Сжатая ZIP-папка».

## Загрузка в Playgama

1. Зайдите в **Playgama Developer Console** и создайте новую игру.
2. **Загрузите zip-архив** билда. Дождитесь автоматической проверки сборки:
   она проверит наличие `index.html`, Bridge и `playgama-bridge-config.json`.
3. Заполните **форму игры**:
   - Название: **Rabbit Reaper** (должно совпадать с заставкой, 3.5.1).
   - Жанр/категория: Action (боевик / hack-and-slash).
   - **Языки: English, Русский** — других не указывайте, иначе их придётся перевести (3.4.3).
   - Устройства: **Desktop и Mobile**.
   - **Ориентация: только альбомная (landscape)** — в портретной платформа покажет
     заглушку «поверните устройство» (1.4.3).
   - Описание и управление (можно взять из раздела ниже).
4. **Обложки и скриншоты** загружаются вручную в консоли (иконка, обложки разных
   размеров, 3–5 скриншотов). Хорошие кадры: главное меню, бой с толпой духов и
   следом косы, босс, экран «Дар жатвы».
5. Откройте **песочницу (sandbox)** из консоли и проверьте игру там — это ближе всего
   к тому, что увидит модератор: реклама, пауза при переключении вкладки, звук.
6. Отправьте игру **на модерацию** (кнопка в консоли). Если вернут — в ответе будут
   номера пунктов требований; по ним легко найти, что поправить.

## Текст для описания

**EN.** *Rabbit Reaper* — a dark anime hack-and-slash. Play as a rabbit reaper
with a giant scythe and cut through endless waves of shadow spirits. Chain
4-hit combos, dash through attacks at the last moment for a PERFECT dodge, parry
spirit bolts back at their casters, execute stunned elites and pick a new Gift of
the Harvest after every wave. Every 10th wave a boss awaits: the Mourning Hollow.

**RU.** *Rabbit Reaper* — мрачный аниме-слэшер. Заяц-жнец с огромной косой против
бесконечных волн теневых духов. Серии из 4 ударов, идеальные уклонения в последний
момент, отражение вражеских сгустков, казни оглушённых элит и новый Дар жатвы после
каждой волны. Каждые 10 волн — босс: Скорбящая Пустота.

**Управление / Controls:** WASD — движение / move · ЛКМ — удар / strike ·
ПКМ (удерж.) — заряженный удар / charged strike · Пробел — рывок / dash ·
Q, E, R — способности / abilities · P — пауза / pause. На телефоне — экранный
джойстик и кнопки / touch joystick and buttons.

## Локальная проверка

```bash
cd docs && python3 -m http.server 8000
# открыть http://localhost:8000
```
Вне Playgama Bridge работает в тестовом режиме (без рекламы) — это нормально.
Отладочные параметры адреса: `?rr_autostart`, `?rr_wave=10`, `?rr_stress=100`.
